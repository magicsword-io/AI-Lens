## Changes

- Accept Copilot CLI's raw `apply_patch` tool arguments, so legitimate file
  edits can reach policy evaluation. JSON-based tool arguments remain supported;
  malformed input is still rejected. Windows authenticated-client validation
  of this fix is pending.
- Ship a Cowork upload ZIP with the Linux x64 executable, adjacent engine,
  default rules and a scoped metadata-only launcher. Runtime state remains
  local to its Linux cloud task; a stopped policy stays stopped.
- Document installed-client checks: Cursor 3.27.22 on Windows 11 ARM64 using
  x64 Lens, and Claude Desktop 4.29.0 launching Cowork's Linux x64 runtime.
  These checks cover observed allow/deny and stopped-policy controls, not every
  subscribed event or execution host. See the
  [verification record](https://github.com/magicsword-io/AI-Lens/blob/main/docs/verification.md)
  for artifact identities and exact coverage.

## Packages and provenance

Extract native ZIPs and keep the executable beside its engine library.
[Getting started](https://magicsword-io.github.io/AI-Lens/getting-started/)
includes OS prerequisites, checksums and the synthetic demo.
Windows requires the Microsoft Visual C++ v14 x64 Redistributable. Packages are
unsigned; macOS may require downloaded-app approval. Intel Macs and other
architectures can build from source.

`SHA256SUMS` covers all four ZIPs. `build-provenance.json` retains the three
native build records. `cowork-plugin-provenance.json` identifies the tagged
source, packaging helpers, launcher, source Linux ZIP and every plugin member.
The Cowork package is for Linux x64 hook execution, including when a Desktop
client launches that cloud runtime; it is not a native Windows/macOS plugin
binary. Earlier releases remain unchanged.
